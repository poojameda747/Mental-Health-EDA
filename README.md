# Mental Health in Tech - EDA

##  Objective
To analyze mental health trends in the tech industry using survey data.

##  Dataset
- Mental Health in Tech Survey
- Contains data about employees, treatment, workplace environment

##  Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

##  Key Insights
- Most affected age group: 25–35
- Mental health impacts work productivity
- Many employees hesitate to discuss mental health
- Lack of company support in some cases

## Conclusion
Mental health is a critical issue in the tech industry. Companies should improve awareness, support systems, and encourage open discussions.
